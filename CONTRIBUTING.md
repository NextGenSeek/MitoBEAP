# Contributing to MitoBEAP

Thank you for your interest in contributing to MitoBEAP!

MitoBEAP is an R package for analysing mitochondrial base editing outcomes, including on-target editing efficiency, off-target editing and bystander edits. Contributions that improve its functionality, reliability, documentation or usability are welcome.

## Reporting bugs

If you encounter a problem, please open an issue in the GitHub repository.

When reporting a bug, please include:
- A description of the problem.
- The steps needed to reproduce it.
- The expected and actual behaviour.
- Any relevant error messages.
- Your R version and operating system, if relevant.

Please avoid sharing sensitive or unpublished experimental data.

## Suggesting improvements

Suggestions for new features, additional analyses or improvements to existing functionality are welcome.

Please open a GitHub issue describing the proposed improvement and how it would benefit users.

## Contributing code

If you would like to contribute code:

1. Fork the MitoBEAP repository.
2. Create a new branch for your changes.
3. Make your changes and test them using appropriate example data.
4. Update the documentation if necessary.
5. Submit a pull request describing your changes.

For substantial changes, please open an issue first to discuss the proposed approach.

## Coding guidelines

- Follow existing coding conventions where possible.
- Keep changes focused and clearly documented.
- Use descriptive variable and function names.
- Document new or modified functions using roxygen2 where appropriate.
- Test new functionality before submitting a pull request.
- Avoid introducing unnecessary dependencies.

## Questions

If you have questions about using or contributing to MitoBEAP, please open a GitHub issue.

Thank you for helping improve MitoBEAP!
